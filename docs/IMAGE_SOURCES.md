## Editorial decisions

- Detailed Microsoft schema illustrations replace the overlapping Mermaid star and snowflake examples. Captions identify the source examples; the article retains its order-line grain and allocation reasoning.
- Official SCD figures show storage changes; the existing Mermaid diagram still explains validation and publication. The Type 2 caption distinguishes the source image date convention from this article's half-open interval example.
- Original Kimball/Inmon and Data Vault illustrations replace their overlapping flows and ER drawing. The hybrid flow stays because it explains the separate downstream responsibilities.
- Lambda and Kappa use the official Azure Architecture Center images. The medallion figure is an original illustration grounded in Databricks documentation, including quarantine and repair. Databricks artwork is not redistributed because its general site terms do not grant public redistribution.
- The lake-platform illustration shows raw retention, table data and log, catalog controls, publication and optional warehouse serving.
- RAG and Kubernetes official images provide component views; their existing Mermaid flows retain the request and workload behavior.
- Shared agent context is an original nested architecture illustration following the user-provided reference structure. It preserves orchestration, artifact and authorization responsibilities without using a Mermaid substitute.

## Maintaining figures

Use a descriptive asset path and a stable figure ID. Include the figure only in the topic that owns the explanation. The static checker validates paths, dimensions, registry references, file signatures, SVG safety and checksums. Browser checks verify successful image loading, complete overview visibility, enlargement, captions, full-size links, keyboard scrolling and page overflow at desktop and mobile widths.
